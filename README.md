# 🐝 Fizyka z Pythonem

Interaktywne lekcje fizyki w zeszytach Jupyter (Google Colab). Zamiast wzorów na tablicy – animacje, suwaki i eksperymenty, które pokazują, **jak działa fizyka**. Przy okazji uczysz się podstaw Pythona (bez przesady – nacisk jest na fizykę).

## Jak zacząć?

1. Kliknij przycisk **„Open in Colab"** przy wybranej lekcji.
2. Zaloguj się kontem Google (potrzebne do uruchamiania kodu w Colabie).
3. Uruchamiaj komórki po kolei przyciskiem ▶ (albo `Shift + Enter`) i eksperymentuj!

Nie musisz nic instalować. Swoje zmiany możesz zapisać przez *Plik → Zapisz kopię na Dysku*.
